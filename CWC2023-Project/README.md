# Cricket World Cup 2023 Project.


## Project Overview
This project analyzes the ICC Cricket World Cup 2023 dataset using Python, Tableau, and Microsoft Power BI. It presents cricket statistics through charts, graphs, and interactive dashboards to understand team performance and match trends.

## Objectives
- Analyze team-wise match appearances and scores.
- Compare runs, fours, sixes, wickets, and run rates.
- Explore cricket venues and match statistics.
- Visualize relationships between different cricket variables.
- Develop interactive dashboards for better understanding of the data.

## Tools and Technologies
- **Python:** Pandas, Matplotlib, Seaborn
- **Jupyter Notebook / Google Colab:** Data analysis and visualization
- **Tableau:** Interactive data visualization
- **Microsoft Power BI:** Dashboard development
- **CSV:** Dataset storage

## Dataset
The project uses the `CWC2023.csv` dataset containing Cricket World Cup 2023 match statistics and related team performance information.

## Implementation
1. Import and inspect the dataset.
2. Clean and prepare the data for analysis.
3. Perform exploratory data analysis.
4. Create visualizations such as bar charts, line charts, pie charts, scatter plots, box plots, violin plots, and correlation heatmaps.
5. Build interactive dashboards using Tableau and Power BI.
6. Interpret the visualizations to identify patterns in team performance.

## Key Insights
- India and Australia recorded the highest match appearances in the tournament.
- Team scores vary across matches, showing differences in batting performance.
- Boundary statistics help compare the scoring contributions of teams.
- Correlation analysis reveals relationships between cricket statistics.
- Interactive dashboards make team and match comparisons easier.

## Project Files
- `CWC2023.csv` – Dataset used for analysis.

## Conclusion
This project demonstrates how data visualization techniques can be used to analyze Cricket World Cup 2023 statistics. Python, Tableau, and Power BI help transform raw cricket data into meaningful visual insights that support team performance comparison and match analysis.
